# 📺 RetroTube

[🌐 Visit RetroTube](https://ian-software.neocities.org/RetroTube/)

**Welcome to RetroTube!**

RetroTube is a retro-inspired video platform project designed to bring back the 2005 classic look and feel of older video-sharing websites.

## 📖 About

RetroTube is an HTML-based project inspired by the classic YouTube experience. It recreates the nostalgic atmosphere of the early internet with a retro-inspired interface.

## ✨ Features

- 📺 Retro-inspired video platform.
- 🎨 Classic website interface.
- 🔍 Video search concept.
- 🖥️ HTML-based project.
- ⚡ Lightweight and simple.
- 🌐 Runs directly in your web browser.
